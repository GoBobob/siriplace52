# เฝ้าระวังน้ำ · สิริ เพลส พหลโยธิน 52

หน้าเว็บไฟล์เดียว (`index.html`) ที่ดึงข้อมูลสดและประมวลผลความเสี่ยงน้ำท่วมรอบโครงการในเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

## แหล่งข้อมูล

| ข้อมูล | แหล่ง | ดึงตรงจากเบราว์เซอร์ได้ |
|---|---|---|
| ระดับคลองหกวา, ระพีพัฒน์, แม่น้ำเจ้าพระยา | ThaiWater (สสน.) `api-v3.thaiwater.net` | ได้ |
| ฝนวัดจริง 24 ชม. (กทม. นนทบุรี ปทุมธานี) | ThaiWater | ได้ |
| คำเตือนภัยอัตโนมัติ | ThaiWater | ได้ |
| เรดาร์ฝน 2 ชม. ล่าสุด | RainViewer | ได้ |
| พยากรณ์ฝนรายชั่วโมงและ 14 วัน | Open-Meteo | ได้ |
| ระดับคลองสอง และน้ำบนถนนแบบสด | สำนักการระบายน้ำ กทม. `now.bangkok.go.th` | **ไม่ได้** ต้องใช้ตัวกลาง (ด้านล่าง) |

ถ้าไม่ได้ตั้งตัวกลาง หน้าเว็บยังทำงานได้ แต่ข้อมูลน้ำบนถนนจะใช้สำเนาของ ThaiWater ซึ่งอาจค้างหลายวัน และจะไม่แสดงคลองสองของ กทม.

## วิธี deploy (เลือกอย่างใดอย่างหนึ่ง)

- **Netlify Drop:** เปิด https://app.netlify.com/drop แล้วลากโฟลเดอร์ที่มี `index.html` ไปวาง
- **Cloudflare Pages:** Workers & Pages → Create → Pages → Upload assets → อัปโหลด `index.html`
- **GitHub Pages:** สร้าง repo ใส่ `index.html` แล้วเปิด Settings → Pages → Deploy from branch

## ตั้งค่าตัวกลางสำหรับข้อมูล กทม. (ไม่บังคับ)

1. Cloudflare → Workers & Pages → Create → Worker → วางโค้ดจาก `worker.js` → Deploy
2. คัดลอกลิงก์ของ Worker เช่น `https://bma-proxy.yourname.workers.dev/`
3. แก้ `index.html` ในส่วน `CONFIG` ให้ `bmaProxy: 'https://bma-proxy.yourname.workers.dev/'`
4. (แนะนำ) ใน `worker.js` เปลี่ยน `ALLOW_ORIGIN` เป็นโดเมนเว็บของคุณ

Worker แคชข้อมูล 5 นาที และยอมให้ดึงแค่ 4 ไฟล์ JSON ที่หน้าเว็บใช้ แพ็กเกจฟรีของ Cloudflare รองรับได้สบาย

## ปรับใช้กับบ้านหลังอื่น

แก้ใน `CONFIG`: `name`, `lat`, `lon` และรายชื่อสถานีใน `canals`, `bmaCanals` (รหัสสถานีดูได้จาก ThaiWater หรือ faonam.com)

## วิธีคำนวณความเสี่ยง

ให้คะแนน 0–3 จาก 6 ตัวชี้วัด: ระยะคลองก่อนล้นตลิ่ง, น้ำบนถนนในรัศมี 4 กม., ฝนวัดได้ 24 ชม., ฝนคาด 48 ชม., พื้นที่ฝนบนเรดาร์ในรัศมี 5 กม., ระดับแม่น้ำเจ้าพระยาที่สามเสน
ตารางเกณฑ์อยู่ท้ายหน้าเว็บ ข้อมูลที่เก่ากว่า 6 ชั่วโมงจะไม่ถูกนับคะแนน

เกณฑ์ฝนอ้างอิงนิยามกรมอุตุนิยมวิทยา ส่วนเกณฑ์อื่นตั้งขึ้นสำหรับหน้านี้ ไม่ใช่เกณฑ์ทางราชการ — ใช้ประกอบการตัดสินใจ ไม่ใช่ประกาศเตือนภัย
